# Security policy

## Supported versions

The latest GitHub release is supported. Pre-release versions are provided for testing and may
change without backward-compatibility guarantees.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's **Report a vulnerability**
feature on the repository Security page and include:

- the affected version;
- a minimal reproducer or GDSII sample, if it can be shared safely;
- the observed impact; and
- relevant Windows version and architecture details.

Avoid uploading confidential production layouts. A synthetic file that triggers the same behavior
is preferred.
