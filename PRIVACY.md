# Privacy Policy

Effective date: August 19, 2026

GDS Preview for Windows Explorer does not collect, store, sell, or transmit personal information,
usage data, telemetry, or GDSII file contents.

All GDSII parsing and preview rendering occurs locally on the user's Windows device. The app does
not contain advertising, analytics, user accounts, or network communication. When the user chooses
to open the included demo, that demo file is copied locally to the user's app-data folder. No user
file is uploaded or shared.

Microsoft Store and Windows may independently process information under Microsoft's own privacy
terms when the app is downloaded, installed, updated, or reviewed. That processing is not performed
by this app.

Questions about this policy can be submitted through the project's public support page:
https://github.com/keikawa/gds-preview-for-windows-explorer/issues

Security-sensitive reports should follow the instructions in `SECURITY.md` instead of using a
public issue.
